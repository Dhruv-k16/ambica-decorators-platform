## Important enquiry form behavior
- Event types are CHECKBOXES, so clients can select multiple functions.
- Event dates are repeatable, so clients can add multiple function dates.
- Services are checkboxes.
- Budget, venue status, guest count, venue and message are included.
- The current demo stores submitted enquiries in browser localStorage only.

## Before production launch
Connect the enquiry form to a real backend/database and notification workflow.
Recommended production stack:
Next.js + TypeScript + PostgreSQL + Prisma + secure admin authentication + Cloudinary for images + email/WhatsApp notifications.
